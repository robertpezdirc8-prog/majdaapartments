# River Kolpa Apartments

Modern, responsive website for River Kolpa Apartments showcasing two properties (Griblje 70 and Griblje 30 b) in Bela Krajina, Slovenia.

## Overview

This is a comprehensive, single-page application designed to showcase River Kolpa Apartments, featuring stunning properties along the Kolpa River in Bela Krajina. The website provides detailed information about both Griblje 70 and Griblje 30 b, including property features, virtual tours, guest reviews, and booking capabilities.

### 🎨 Visual Design

## Properties Featured

### Griblje 70
- **Style**: Renovated house with pergola
- **Capacity**: 7 + 5 persons
- **Features**: Terrace, jacuzzi, enclosed garden
- **Location**: 10 minutes walk from Kolpa River
- **Amenities**: WiFi, parking, climate control, wood stove

### Griblje 30 b
- **Style**: Modern house with jacuzzi
- **Capacity**: 2 apartments (4 persons total)
- **Features**: Jacuzzi under deck, terraced garden
- **Amenities**: WiFi, kitchen facilities, washer/dryer

## Usage

### Basic Navigation
- Use navigation links or hash links (`#s-h70`, `#s-h30b`, etc.)
- Scroll-based section switching with hash tracking
- Mobile navigation accessible via hamburger menu

### Property Viewing
- Click on property cards to navigate to detailed views
- Use lightbox controls for detailed image examination
- Zoom and pan capabilities for virtual tours

### Contact & Booking
- Fill out contact forms for property inquiries
- Book directly through email integration
- Access location maps for directions
